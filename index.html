六阶段框架

覆盖企业从 0 到 N 的完整路径

01
PHASE 01
方向探索期
→ 识别被压抑的需求
用户还没说清楚自己的痛苦，但已经在用奇怪的方式绕过问题。那些笨办法，就是方向的信号灯。
02
PHASE 02
产品定义期
→ 问题-方案匹配验证
你解决的问题，真的是用户最痛的问题吗？这一阶段的用户证据，决定了你是否走在对的赛道上。
03
PHASE 03
研发期
→ 低成本原型 + 真实用户测试
不是做完才验证，而是边做边验证。用最低成本的原型，让真实用户告诉你哪里错了。
04
PHASE 04
销售期
→ 高价值用户识别与分层
不是所有用户都值得同等投入。谁付了最多钱、用得最频繁、带来了最多推荐？ 那就是你的核心用户。
05
PHASE 05
规模化发展期
→ 护城河构建
内容、社区、信任机制——这些软性资产往往比技术壁垒更难被复制，也更持久。
06
PHASE 06
融资期
→ 投资人看重的用户证据类型
投资人不只看数字，他们看的是数字背后的用户行为逻辑。哪些证据最有说服力，这一阶段告诉你。
目标用户

三类"正在进行时"的创业者

⚙
正在做出产品
已有原型或早期销量，但不确定方向对不对、下一步该验证什么。需要一面镜子，照出自己的盲区。
📈
正在提升认知
不想靠"蛮干"积累经验，希望系统化训练战略判断力。用真实商业案例校准直觉，比看书快 10 倍。
👥
正在打造组织
3-30 人团队，需要让全员建立"用户洞察驱动决策"的工作语言。让团队说同一种战略语言。
共同特征 / COMMON TRAITS

风险与边界

我们选择坦诚

⚠ 风险
AI 可能编造或曲解信息
缓解措施
每个证据附原始链接，要求用户交叉验证。报告是出发点，不是终点。
⚠ 风险
公开信息不完整（尤其早期公司）
缓解措施
允许用户手动补充已知信息；报告会标注"信息缺口"，缺口本身也是洞察。
⚠ 风险
不能替代行业深度认知
缓解措施
本工具只提供"用户视角"的战略判断，技术、供应链、财务仍需用户自己判断。
⚠ 风险
不保证商业成功
缓解措施
训练的是"少犯低级错误"，不是"一定能成"。模拟器让你的直觉更有根基。
